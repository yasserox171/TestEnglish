# ربط نتائج الاختبار بـ Google Sheets

النتائج تُرسل إلى جدول Google Sheets عبر Google Apps Script. لا حاجة لخادم
ولا لمفاتيح API: السكربت يعمل داخل حساب Google نفسه.

**الحساب المستهدف:** `yasser7aziz@gmail.com`

---

## خطوات التركيب (مرة واحدة)

### 1. أنشئ الجدول
افتح <https://sheets.new> وأنت مسجّل الدخول بـ `yasser7aziz@gmail.com`،
وسمِّ الملف مثلاً **English Learning Test**.

### 2. افتح محرّر السكربت
من القائمة العلوية: **Extensions** ← **Apps Script**.

### 3. الصق الكود
امسح كل ما في المحرّر، والصق محتوى ملف [`Code.gs`](Code.gs) كاملاً، ثم
احفظ بـ `Ctrl+S`.

### 4. انشر كتطبيق ويب
- **Deploy** ← **New deployment**
- اضغط أيقونة الترس بجانب *Select type* واختر **Web app**
- اضبط الحقلين:
  - **Execute as:** `Me (yasser7aziz@gmail.com)`
  - **Who has access:** `Anyone` ← *ضروري*، وإلا لن تصل النتائج
- **Deploy**

### 5. اسمح بالصلاحيات
ستظهر شاشة تحذير من Google لأن السكربت غير مُراجَع منها:
**Advanced** ← **Go to … (unsafe)** ← **Allow**.

هذا طبيعي مع أي سكربت شخصي، والصلاحية المطلوبة هي الكتابة في جدولك أنت.

### 6. انسخ الرابط
ستحصل على رابط ينتهي بـ `/exec`، على هذا الشكل:

```
https://script.google.com/macros/s/AKfycb..../exec
```

**تحقّق منه:** افتحه في المتصفح. يجب أن يظهر:

```json
{"status":"ok","service":"English Learning Test"}
```

### 7. اربطه بالموقع
في ملف [`../index.html`](../index.html) ابحث عن `CONFIG` وضع الرابط:

```js
var CONFIG = {
  apiEndpoint: "https://script.google.com/macros/s/AKfycb..../exec",
```

ثم على الخادم:

```bash
cd /home/ubuntu/TestEnglish && git pull
```

التغيير يظهر فوراً بلا إعادة تشغيل.

## ما الذي يُسجَّل

صف واحد لكل مجتاز في ورقة **Résultats**:

| العمود | المحتوى |
|---|---|
| ID | معرّف فريد للمحاولة (يمنع تكرار الصفوف) |
| Date | تاريخ ووقت الإرسال |
| Nom / Téléphone | الاسم ورقم الهاتف |
| Score / Total / Pourcentage | الدرجة من 10 والنسبة |
| Niveau | المستوى (A1 … B1) |
| Durée | المدة المستغرقة mm:ss |
| Envoi auto | `oui` إذا أُرسل تلقائياً عند انتهاء الوقت |
| Langue | لغة الواجهة وقت الاختبار (`fr` أو `ar`) |
| Q1 … Q10 | إجابة المجتاز في كل سؤال متبوعة بـ ✓ أو ✗ |

## ملاحظات

**التكرار مستبعَد.** الصفحة تحتفظ بالنتيجة محلياً وتعيد المحاولة حتى تنجح
(مفيد على الإنترنت الضعيف). السكربت يتجاهل أي إرسال بمعرّف `ID` مسجَّل
مسبقاً، فلا يتولّد صفّان لنفس المحاولة.

**لا تفقد نتيجة.** إن كان الزائر خارج التغطية، تبقى النتيجة في متصفحه
وتُرسل تلقائياً عند عودة الشبكة.

**عند تعديل `Code.gs`** لاحقاً: لا يكفي الحفظ. اذهب إلى
**Deploy** ← **Manage deployments** ← أيقونة القلم ← *Version:* **New version**
← **Deploy**. الرابط `/exec` يبقى كما هو.
